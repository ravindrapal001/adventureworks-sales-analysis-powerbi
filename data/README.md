# AdventureWorks Dataset

This folder contains the source datasets used in my Power BI sales analysis project.

## Dataset Files

- `AdventureWorks Sales Data 2020.csv` — Sales records for 2020.
- `AdventureWorks Sales Data 2021.csv` — Sales records for 2021.
- `AdventureWorks Sales Data 2022.csv` — Sales records for 2022.
- `AdventureWorks Customer Lookup.csv` — Customer information.
- `AdventureWorks Product Lookup.csv` — Product information.
- `AdventureWorks Product Categories Lookup.csv` — Product category information.
- `AdventureWorks Product Subcategories Lookup.csv` — Product subcategory information.
- `AdventureWorks Calendar Lookup.csv` — Calendar and date information.
- `AdventureWorks Territory Lookup.csv` — Sales territory information.
- `AdventureWorks Returns Data.csv` — Product return records.

## Purpose

These datasets are used to practise data extraction, transformation, cleaning, data modeling, and business intelligence reporting using Microsoft Power BI.

## Data Preparation

The datasets are imported into Power BI, transformed using Power Query, and connected through relationships to support further analysis.
