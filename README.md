# AdventureWorks Sales Analysis | Power BI

## Project Overview

This project focuses on developing an interactive sales analytics solution using Microsoft Power BI and the AdventureWorks dataset. The objective is to prepare, transform, model, and analyze sales-related data to support data-driven business decision-making.

I am developing this project step by step, documenting my daily progress from data preparation and data modeling to DAX calculations, dashboard development, and business insights.

## Project Objectives

- Import and prepare data from multiple CSV files.
- Clean and transform data using Power Query.
- Establish relationships between fact and dimension tables.
- Develop a structured data model.
- Create DAX measures and business KPIs.
- Build interactive Power BI dashboards.
- Identify sales trends and actionable business insights.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (planned / in progress)
- Data Modeling
- CSV Data Sources
- GitHub for version control and project documentation

## Dataset Description

The project uses AdventureWorks sample business data, including:

- Sales data for 2020, 2021, and 2022
- Customer lookup data
- Product lookup data
- Product categories and subcategories
- Calendar lookup data
- Sales territory lookup data
- Product returns data
