# Calculated Tables – AdventureWorks Sales Analysis

## 1. Overview

This document covers the additional calculated tables created in Microsoft Power BI using DAX as part of the AdventureWorks Sales Analysis project.

The objective is to create separate analytical tables containing month-start dates and product category information to support reporting, filtering, grouping, and business analysis.

## 2. Calculated Table: Start of Month

**Table Purpose:** Store month-start dates for monthly analysis.

### Objective
Create a table containing the starting date of each month to support month-level reporting and date-based analysis.

### Business Questions
- How can monthly periods be represented consistently?
- How can sales and other business metrics be grouped by month?
- How can month-start dates support monthly reporting?

### Expected Structure
| Column | Description |
|---|---|
| Start of Month | First date of the respective month |

### Business Applications
- Monthly sales analysis.
- Month-over-month comparisons.
- Monthly trend visualizations.
- Date-based grouping and filtering.

**Implementation:** Calculated table created in Power BI using DAX.

**DAX Formula:** To be added from the actual Power BI formula bar.

## 3. Calculated Table: Category Name

**Table Purpose:** Store category information for product-level analysis.

### Objective
Create a separate table containing category names to support category-based reporting and analysis.

### Business Questions
- What product categories are available?
- How can sales performance be compared across categories?
- How can category information be used for report filtering and grouping?

### Expected Structure
| Column | Description |
|---|---|
| Category Name | Product category name |

### Business Applications
- Product category analysis.
- Category-wise sales comparisons.
- Category-based filtering.
- Sales and return performance reporting.

**Implementation:** Calculated table created in Power BI using DAX.

**DAX Formula:** To be added from the actual Power BI formula bar.
